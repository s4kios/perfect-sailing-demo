# Perfect Sailing client demo

Static client preview of the Perfect Sailing booking platform.

Includes yacht galleries, sailing area pages, an optimised hero video, and read-only example availability from Google Sheets. Booking requests are demonstrations only: no requests are sent, no payments are taken, and no yacht is reserved.

Publish with GitHub Pages from the main branch, root directory. All links are relative and support a project subdirectory.

Fonts are self-hosted with their OFL notices in assets/fonts. Site copy, branding, photographs and footage are supplied for this client project; no general reuse licence is granted.
